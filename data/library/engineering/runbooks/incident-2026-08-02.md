# Postmortem: Search outage, 2 August 2026

## Summary
Search was unavailable for 23 minutes between 14:05 and 14:28 UTC. Payments were not affected.

## Root cause
A Postgres primary failover left PgBouncer pointing at the old primary, so search queries timed out.

## Action items
Add PgBouncer health checks against the current primary, and run a failover drill every quarter.
